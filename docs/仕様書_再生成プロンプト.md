### 🪄 自動作成のアルゴリズム（この順序で）

1. **条件反映**: 「必ず出勤」→出勤（夜間支援従事者は夜勤、他は日勤）で固定。「必ず休み」→休で固定
2. **公休の均等仮置き**: 職員ごとに目標勤務日数（常勤=`ceil(基準時間÷1回の時間)`※夜勤者は16hで割る、非常勤=16日）を計算し、休むべき日数を**月内に等間隔で仮置き**（希望休・休み条件の日を優先的に充当）。以降の割当は3段階の空き判定で行う: mode0=仮置き公休も避ける → mode1=仮置き公休を使ってよい → mode2=時間上限超過も許す
3. **日中の配置（夜勤より先）**: 各拠点・各日1名以上（夜間支援従事者は昼に使わない）。優先順位は **mode0=拠点の常勤→拠点の非常勤→他拠点の常勤(応援)→他拠点の非常勤**。mode1以上（公休予定日や時間上限に食い込む段階）は**非常勤(バイト)の余力→応援→本人の順**にして常勤の公休と連勤を守る
4. **夜勤（日中配置の後）**: 夜間支援従事者がいる事業所は毎日1名。優先順位は **夜間支援従事者 → 常勤の余った勤務時間（自動兼務） → 非常勤(バイト)で穴埋め**。置けない日は空けて警告
5. **常勤の時間充足**: 基準時間に届くまで日勤を追加。追加日は仮置き公休以外の空き日から**等間隔に選ぶ**（公休が偏らない）

### データ保存キー（localStorage）

- `nl_staff`: 職員配列（初回シード。構造が古ければ再シード）
- `nl_punch_{職員id}_{Y-M-D}`: 打刻配列 `{type,time,edited,comment,off?,place?,raw?,editedBy?,addedBy?}`（Y-M-Dはゼロ埋めなし。**夜勤は日をまたいでも「勤務日」1つにまとめる**。`time`は予定に丸めた時刻・`raw`は実際に押した時刻。**1日に「出勤→退勤」が複数組あってよい**）
- `nl_brk_{職員id}_{Y-M-D}`: その日の休憩時間（分）。通し・夜勤の既定60分をプルダウンで変えたときに保存
- `nl_kibou_{職員id}`: 希望休配列 `{date,type,note,status}`（typeは「希望休（終日）」または自由記述）
- `nl_mshift2_{職員id}_{YYYY-MM}`: 月次シフト配列（日数分の `{k:区分, w:勤務先拠点id, half?:"am"|"pm"（半日のみ）, seg?:{mh,eh,mw,ew}, note?, col?}`）
- `nl_mustwork_{職員id}`: 条件配列 `{date,reason,type:"work"|"off"}`
